# 工账 APK —— 模拟器运行与演示指南

> 适用版本：`app-debug.apk`（versionName **2.8.0** / versionCode **1**）
> 包名 **`com.gongzhang.app`**　|　体积 **10032.8 KB**　|　debug 签名（可直装，无需签名校验）
> 适配范围：**minSdk 24**（Android 7.0）~ **targetSdk 36**
> CPU 架构：**arm64-v8a / armeabi-v7a / x86 / x86_64 全打包** → 任何模拟器原生可跑，**不需要 arm 转译**

---

## 0. 本机现状盘点（2026-10-31 实测）

| 项目 | 实测结果 | 影响 |
|---|---|---|
| Android SDK 平台 | `android-36`、`android-37.0` | ✅ 够用 |
| `adb.exe` | `C:\Users\zhaoqiulin7\AppData\Local\Android\Sdk\platform-tools\adb.exe` | ✅ 可用 |
| `emulator.exe` | 存在 | ✅ 官方模拟器程序在 |
| **系统镜像 system-images** | **无** | ❌ AVD 必须先下载镜像（约 1~2GB） |
| **已创建 AVD** | **无** | ❌ 需新建 |
| **Hyper-V / HypervisorPlatform / VirtualMachinePlatform** | **全部 Disabled** | ❌ 官方 AVD 起不来或极慢；**雷电模拟器不受此限制** |
| 第三方模拟器（雷电/MuMu/夜神/蓝叠） | **均未安装** | 需下载安装 |

### 结论：推荐顺序

| 排序 | 方案 | 为什么 |
|---|---|---|
| **① 首选** | **雷电模拟器 9**（LDPlayer 9） | 本机 Hyper-V 关着也能跑，不用改系统设置、不用重启；装完拖 APK 即用；自带 adb |
| ② 备选 | **MuMu 模拟器 12** | 性能与兼容好，但**需要先开启** Hyper-V/虚拟机平台（要重启一次） |
| ③ 官方可控 | **Android Studio AVD** | API 版本可精确选择（建议 API 33/34 带 Google APIs），便于验证通知与权限弹窗；代价是要开虚拟化 + 下镜像 |
| ④ 兜底 | **真机** | 相机、通知、分享最真实；`adb install -r` 一条命令 |

## 1. 方案 A：雷电模拟器（推荐，最快上手）

### 1.1 安装与配置

1. 官网下载 **雷电模拟器 9**（ldplayer.net），安装到非中文路径（例如 `C:\ldplayer9`）；
2. 启动后进入「设置 → 手机」：
   - 机型：选 **Pixel 5** 或 **自定义 1080×2340**；
   - **分辨率**：手机版 1080×2340（DPI 440）—— 更接近真机；
   - **性能**：CPU 4 核 / 内存 4GB（默认 2 核 2GB 跑 WebView 会偏卡）；
   - **安卓版本**：优先选 **Android 9（64 位）** 或 **Android 12**。
     > ⚠️ 版本选择的坑：Android **13+** 才会弹 `POST_NOTIFICATIONS` 运行时权限弹窗；
     > Android 12/9 默认授予通知权限。想演示「权限申请流程」就选 13+，想省事就选 12。
3. 打开「设置 → 其他设置」里的 **ADB 调试**（默认开）。

### 1.2 连接 adb

雷电自带 adb，端口固定（多开时递增）：

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb connect 127.0.0.1:5555        # 雷电主实例；第 2 个窗口 5557，第 3 个 5559
& $adb devices
# 期望输出：
# List of devices attached
# 127.0.0.1:5555    device
```

若提示 `cannot connect`，用雷电自带的 adb（在雷电安装目录 `adb.exe`）重试。

### 1.3 安装 APK（两种方式任选）

```powershell
# 方式一：adb（推荐，可看返回码）
& $adb -s 127.0.0.1:5555 install -r "d:\workbuddy工作文件\装修施工管理记账APP\android\app\build\outputs\apk\debug\app-debug.apk"
# 成功输出：Success

# 方式二：直接把 APK 拖进模拟器窗口（雷电支持拖拽安装）
```

### 1.4 启动

```powershell
# 命令行启动（可用于脚本化演示）
& $adb -s 127.0.0.1:5555 shell monkey -p com.gongzhang.app -c android.intent.category.LAUNCHER 1

# 或：在模拟器桌面点「工账」图标
```

## 2. 方案 B：Android Studio AVD（官方，API 可控）

### 2.1 开启硬件加速（**必须，且需重启一次**）

```powershell
# 以管理员身份打开 PowerShell
Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform -All
Enable-WindowsOptionalFeature -Online -FeatureName HypervisorPlatform -All
# 重启电脑
```

> 若 BIOS 里 VT-x 没开，需进 BIOS 打开「Intel Virtualization Technology / SVM Mode」。

### 2.2 下载系统镜像并创建 AVD

```powershell
$sdk = "$env:LOCALAPPDATA\Android\Sdk"
# ① 下载镜像（约 1.5GB）：选带 Google APIs 的，才能验证通知
& "$sdk\cmdline-tools\latest\bin\sdkmanager.bat" "system-images;android-34;google_apis;x86_64" "platform-tools" "emulator"
# 若 cmdline-tools 未安装，用 Android Studio → SDK Manager 图形界面安装同样两项

# ② 创建 AVD
& "$sdk\cmdline-tools\latest\bin\avdmanager.bat" create avd -n GongZhang34 `
    -k "system-images;android-34;google_apis;x86_64" -d "pixel_5" --force

# ③ 启动
& "$sdk\emulator\emulator.exe" -avd GongZhang34 -gpu host -no-snapshot-save
```

推荐 AVD 配置：

| 项 | 建议值 | 理由 |
|---|---|---|
| Device | Pixel 5（1080×2340，440dpi） | 主流真机尺寸 |
| System Image | **Android 13/14（Google APIs）x86_64** | 验证 `POST_NOTIFICATIONS` 权限弹窗 |
| Graphics | **Hardware - GLES 2.0**（或 host） | 软件渲染下 SVG 图表会明显掉帧 |
| RAM | 2048 MB 以上 | WebView + IndexedDB |
| 摄像头 | 前后都设为 **Emulated**（或 webcam 直通） | 否则「📷 拍照」无摄像头可用 |
| 存储 | 4096 MB | 放得下压测数据（5000 笔 + 200 图） |

### 2.3 安装与启动

```powershell
& $adb install -r "…\app-debug.apk"        # AVD 会自动出现在 adb devices（emulator-5554）
& $adb shell monkey -p com.gongzhang.app -c android.intent.category.LAUNCHER 1
```

## 3. 方案 C：MuMu 模拟器 12

- 需先开启 Hyper-V/虚拟机平台（同 2.1）；
- adb 端口：**`127.0.0.1:16384`**（MuMu 12），多开为 16385、16386…

```powershell
& $adb connect 127.0.0.1:16384
& $adb -s 127.0.0.1:16384 install -r "…\app-debug.apk"
```

|---|---|---|---|
| V8 | 设置 → 提醒与预警 → **发送测试通知** | 通知栏出现「🔔 测试通知」 | 最省事的演示点，立即可见 |

| V19 | 导入压测备份：`adb push out\压测备份.json /sdcard/Download/` → 导入恢复 | 5000 笔数据进入，各页 < 1.5s | 压测数据 `npm run stress` 生成 |

### 4.3 模拟器**测不准**、必须真机的项

| 项 | 原因 |
|---|---|
| 国产 ROM（小米/华为/OPPO/vivo）通知白名单 | 模拟器是原生 AOSP，不会拦后台通知 |
| 真实相机成像质量、对焦、EXIF 方向 | 模拟器摄像头是虚拟场景 |
| 微信分享的真实接收 | 模拟器通常没装微信 |
| 性能手感（冷启动 < 1.5s） | 模拟器 CPU/GPU 与真机差异大 |
| 刘海/挖孔/折叠屏/大字体 | 需特定机型 |

## 5. 常见问题与解决方案

### 5.1 安装阶段

| 现象 | 原因 | 解决 |
|---|---|---|
| `adb devices` 为空 | 模拟器未开 ADB 调试 / 端口不对 | 雷电：设置里开 ADB；端口 5555。MuMu12：16384。AVD：自动出现 `emulator-5554` |
| `adb connect` 后状态 `offline` | 模拟器未完全启动 | 等桌面出现后重试；或 `adb kill-server && adb start-server` |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 同名包残留数据签名冲突 | `adb uninstall com.gongzhang.app` 后重装 |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | 模拟器存储满了 | 设置里扩容到 4GB+，或 `adb shell pm clear com.gongzhang.app` |
| `INSTALL_FAILED_OLDER_SDK` | 模拟器系统版本 < Android 7.0 | APK 要求 **minSdk 24**；换 Android 9+ 的模拟器 |
| `INSTALL_PARSE_FAILED_NO_CERTIFICATES` | APK 被截断/损坏 | 重新 `gradlew assembleDebug`；确认拷贝完整（10MB） |

### 5.2 启动与运行

| 现象 | 原因 | 解决 |
|---|---|---|
| **打开即白屏** | Web 资源没打进去 / JS 报错 | ① `adb logcat \| findstr /i chromium` 看 JS 报错；② 确认 `npx cap sync android` 已执行；③ 确认 `www/` 已 `node build.js` 生成 |
| **黑屏卡在启动画面** | 冷启动慢（模拟器 CPU 弱） | 等 10~20s；仍不行看 logcat 是否 `WebView` 加载失败 |
| 页面很卡、SVG 图表掉帧 | 模拟器用了软件渲染 | AVD 改 Graphics 为 **Hardware**；雷电在设置里开「高帧率」并把 CPU 调到 4 核 |
| 中文显示方块 | 模拟器系统缺中文字体 | 换官方 Google APIs 镜像，或装一个中文输入法/字体 |
| 修改代码后模拟器没变化 | 没重新同步 | 必须走完整流程：`node build.js` → `npx cap sync android` → `gradlew assembleDebug` → 重装 APK |

### 5.3 通知相关

| 现象 | 原因 | 解决 |
|---|---|---|
| 点「发送测试通知」没反应 | Android 13+ 权限未授予 | 先点「开启通知」→ 系统弹窗选「允许」 |
| 权限弹窗不出现（Android 12 及以下） | `POST_NOTIFICATIONS` 是 Android 13 才引入的 | 正常现象，通知可直接弹；要演示权限流程请换 API 33+ 镜像 |
| 到期通知**没弹** | ① 节点日期不是未来；② 模拟器时间没到；③ 通知开关关了 | 建节点时到期日选明天；用 `adb shell su 0 date` 改模拟器时间；确认设置里开关已开 |
| 通知弹了但点击不跳转 | extra.pid 为空 | 节点必须关联项目；检查 `Bridge.notify.onClick` |

### 5.4 相机相关

| 现象 | 原因 | 解决 |
|---|---|---|
| 点「📷 拍照」**完全没反应** | 老版本会静默失败（已修复） | 用当前 APK（12:18 之后构建的），应出现 toast 提示 |
| toast「未能获取照片：…」 | 模拟器无摄像头 / 权限被拒 | **改用「🖼 相册」**选图；或 AVD 里把前后摄像头设为 Emulated 后重建快照 |
| 相册也选不了图 | 模拟器没有内置图片 | 先 `adb push 一张图.png /sdcard/Pictures/` 再选 |
| 拍照后缩略图不显示 | `convertFileSrc` 转换后的 URL 取不到 | 看 logcat 是否 fetch 失败；确认 `androidScheme: https` 未被改动 |

### 5.5 数据相关

| 现象 | 原因 | 解决 |
|---|---|---|
| 卸载重装后数据没了 | Android 正常行为（卸载清私有目录） | 符合预期；用「导出备份」留底，重装后导入 |
| 导入压测备份后很卡 | 5000 笔 + 200 图确实重 | 这正是压测目的；记录各页耗时，> 1.5s 则按 ADR 重新评估存储方案 |
| 金额全是 `¥****` | `hideMoney` 被打开 | 我的 → 设置 → 外观里关掉「隐藏金额」 |
| 首页空白、没项目 | 首次向导选了「空白开始」 | 设置 → 数据安全 → 还原演示数据 |

## 6. 10 分钟演示脚本（建议顺序）

```
1. 冷启动            → 展示无白闪 + 启动闪屏                       （30s）
2. 首次运行向导      → 选「演示账本」，首页 8 个区块一次看到        （60s）
3. 记一笔            → 填金额 → 📷/🖼 取凭证 → 保存 → 首页数字变化   （90s）
4. 通知              → 设置 → 提醒与预警 → 开启通知 → 发送测试通知  （60s）
5. 预排程            → 建「明天到期」节点 → 改模拟器时间 → 通知自弹 （120s）
6. 返回键            → 二级页返回 → 首页双击退出                    （30s）
7. 统计              → 双口径切换、5 维拆解、长图分享               （90s）
8. 资金预测 / 对比   → 8 周滚动缺口、多项目同比                     （60s）
9. 数据安全          → 导出备份（唤起系统分享）→ 说明可回收站回滚    （60s）
10. 杀进程重开       → adb shell am kill → 数据仍在                 （30s）
```

## 7. adb 命令速查

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"

# 连接与设备
& $adb devices
& $adb connect 127.0.0.1:5555          # 雷电
& $adb connect 127.0.0.1:16384         # MuMu12
& $adb kill-server; & $adb start-server

# 安装 / 卸载 / 启动 / 停止
& $adb install -r "…\app-debug.apk"
& $adb uninstall com.gongzhang.app
& $adb shell monkey -p com.gongzhang.app -c android.intent.category.LAUNCHER 1
& $adb shell am force-stop com.gongzhang.app
& $adb shell am kill com.gongzhang.app          # 模拟"进程被杀"，验证数据持久化

# 日志（最关键，白屏/崩溃都靠它）
& $adb logcat | findstr /i "chromium gongzhang Capacitor AndroidRuntime"

# 清数据（等于恢复出厂，用来重现首次运行向导）
& $adb shell pm clear com.gongzhang.app

# 传文件到模拟器（压测备份 / 相册图片）
& $adb push "out\压测备份.json" /sdcard/Download/
& $adb push "test.png" /sdcard/Pictures/

# 改模拟器时间（验证预排程通知，需 root）
& $adb shell su 0 date 11010900.00      # 11月1日 09:00（格式 MMDDHHmm[[CC]YY][.ss]）

# 截图（写演示材料用）
& $adb exec-out screencap -p > screen.png
```

## 8. WebView 远程调试（查 JS 问题的最有效手段）

debug 构建的 APK 支持 WebView 调试：

1. 模拟器里打开「工账」；
2. 本机 Chrome 打开 **`chrome://inspect`**；
3. Devices 里应出现 `com.gongzhang.app` → 点 **inspect**；
4. 就能用 DevTools 的 Console 看 JS 报错、Application → IndexedDB 直接查库。

> 若 `adb devices` 能看到设备但 `chrome://inspect` 看不到，执行
> `adb shell setprop debug.capacitor.webview true` 后重启 App（部分镜像需要）。
