## 二、三个必须知道的坑

### 坑 1：系统自带的 JDK 27 太新

```
BUILD FAILED
> BUG! exception in phase 'semantic analysis' ... Unsupported class file major version 71
```

`major version 71` = Java 27。**Gradle 8.14 只支持到 Java 23**。
必须显式指定 JDK 21：

```bash
source scripts/env.sh
```

> ⚠️ Git Bash 下 `JAVA_HOME` 必须是 **Windows 风格**（`C:/jdk21/jdk-21.0.2`），
> 而 PATH 里要用 **POSIX 风格**（`/c/jdk21/jdk-21.0.2/bin`）。`scripts/env.sh` 已处理这个差异。

### 坑 2：官方下载源不通

| 用途 | 官方源 | 本机状态 | 改用 |
|---|---|---|---|
| Gradle 发行包 | `services.gradle.org` | ❌ 超时 | `mirrors.cloud.tencent.com/gradle/` |
| JDK | `api.adoptium.net` | ❌ 不通 | `mirrors.huaweicloud.com/openjdk/` |
| Maven 依赖 | `repo1.maven.org` | ✅ 可用 | 保持默认 |

Gradle 镜像改法（`build-android.sh` 已自动处理）：

```properties
# android/gradle/wrapper/gradle-wrapper.properties
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.14.3-all.zip
```

JDK 21 下载：

```
https://mirrors.huaweicloud.com/openjdk/21.0.2/openjdk-21.0.2_windows-x64_bin.zip
```
解压到 `C:\jdk21`（得到 `C:\jdk21\jdk-21.0.2`）。

### 坑 3：Windows 缓存目录锁

```
Could not move temporary workspace (...) to immutable location (...)
```

Gradle 的 transforms 缓存在 Windows 上偶发被占用。**一律加 `--no-build-cache`**：

```bash
./gradlew assembleDebug --no-daemon --no-build-cache
```

若仍失败：删除 `~/.gradle/caches/8.14.3/transforms` 后重试。

## 三、日常命令

```bash
# 1. 检查环境
source scripts/env.sh --check

# 2. 一键出 APK（debug）
bash scripts/build-android.sh

# 3. 一键出 APK（release，需先配好签名环境变量）
bash scripts/build-android.sh release

# 4. 装到已连接设备
adb install -r android/app/build/outputs/apk/debug/app-debug.apk

# 5. 看 WebView 日志（排查 JS 报错）
adb logcat | grep -i chromium
```

## 四、签名配置（阶段 5 用）

签名信息**不要写进仓库**，用环境变量：

```bash
export ZX_KEYSTORE=/path/to/release.keystore
export ZX_KEY_ALIAS=zx
export ZX_KEY_PASSWORD=***
```

keystore **务必多处备份**——丢了就无法给已安装用户发覆盖升级。

## 五、新机器复现步骤

1. 装 Node 22（≥20 即可）
2. 装 Android Studio 或纯 command-line tools + platform-37 + build-tools-36
3. 下 JDK 21（华为云镜像）→ 解压 `C:\jdk21`
4. `cd app && npm i @capacitor/core @capacitor/cli @capacitor/android`
5. `source scripts/env.sh --check` 确认全绿
6. `bash scripts/build-android.sh`

> 首次构建需下载 Gradle 发行包（约 200MB，走镜像）+ Maven 依赖，可能耗时 5~15 分钟；
> 之后增量构建约 1~3 分钟。
