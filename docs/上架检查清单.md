## 6. 16KB 页对齐复验（升级 NDK/AGP 后必做）

```powershell
# 用 Android Studio → Build → Analyze APK 看 lib/*.so 是否有警告；或：
& "$bt\zipalign.exe" -c -P 16 4 app-release.apk
```

历史结论（2.10.0）：8 个 `.so` 的 ELF `p_align` 均为 `0x4000`（16KB），**通过**。
